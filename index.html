Meet the data

The workshop agent sits on one schema of synthetic P-card data covering FY2025 and FY2026 (July 2024 through June 2026), with about 1,800 cards and 180,000 purchases. Every table and column has a plain-English description in Unity Catalog. Genie reads those descriptions, which is a big part of why it can turn your words into the right query.

Schema osa_pcard_review (in the catalog your data team chose): a statewide view of purchasing card activity across 12 agencies.

TableGrainWhat's in it
agencies1 row / agencyAgency code and name.
agency_budgets1 row / agency / fiscal yearEach agency's P-card budget for FY2025 and FY2026.
cardholders1 row / cardAgency, card status, single-purchase and monthly limits, employee status, and a termination date if the employee has left.
transactions1 row / purchaseDate and time, amount, merchant, merchant category code (MCC), and whether a receipt is attached.
merchant_categories1 row / MCCCategory description and whether the category is blocked under card policy.
monthly_statements1 row / card / monthStatement total, whether it was reconciled, the reconciliation date, and the approver.
The data stops on June 30, 2026. When you say "last 90 days" or "yesterday", the agent counts back from that date, not from today.
Things planted in the data for you to find: split purchases kept just under a card's limit, purchases on cards after the employee left, blocked merchant categories, weekend and late-night activity, missing receipts, and statements reconciled late or not at all.

1 Genie One, Genie Agents, and trust

Goal: know where Genie lives, what each part is for, and why its answers are safe to work with. 12:00 · 10 min

Genie One

Your home page for data at OSA (it used to be called Databricks One). One search bar for dashboards, Genie Agents and apps, plus a full-screen Chat, For you recommendations, and a sidebar with Domains, Scheduled tasks and Documents.

Genie Agents

A chat focused on one subject, such as P-card activity, built by the data team on curated tables. Genie Agents used to be called Genie spaces. The agent already knows the tables, the definitions and the business terms, so you can just ask.

Why you can trust what it shows you

  • It only sees what you can see. Every answer runs with your own Unity Catalog permissions. Row filters and column masks apply automatically, so two people can ask the same question and see different results.
  • It shows its work. Every answer comes with the query Genie ran, so you can check it the same way you'd check a colleague's spreadsheet.
  • It can still be wrong. Genie is a fast first draft, not a second reviewer. Verify before a number goes into a workpaper or a report.
Names change between releases. If a button isn't exactly where this guide says, look for the same word nearby.

Agent mode: multi-step research

For open-ended questions, switch the chat to Agent mode. Genie plans several queries, runs them, and writes up what it found with tables, charts and citations. It takes longer than a normal answer. Click Answer now to stop early, or Download PDF to keep the write-up.

4 Schedule and customize

Goal: have Genie do the routine checks for you, and teach it how you like to work. 12:35 · 15 min

Scheduled tasks

A scheduled task asks a question for you on a set schedule, posts the answer to a chat thread, and can email you the results with a PDF attached. You don't need special permissions to create one.

Every morning, list any new P-card transactions from the previous day at blocked merchant categories or on cards whose holder has a termination date. Include agency, cardholder, merchant and amount.

Because the workshop data stops on June 30, 2026, this task returns the same rows every day. On live data, each run picks up the new activity.

Financial Audit idea

Weekly: statements still unreconciled after 30 days, by agency, with the dollar total.

Performance Audit idea

Monthly: missing-receipt rate by agency compared with last month.

Make it yours

Memory

Tell Genie something once and it applies it in later chats. Try: Remember: when I say FY, I mean the NC fiscal year, July 1 to June 30. or Remember that I prefer results sorted by dollar amount, largest first.

Skills Preview

A skill is a short instruction file you upload to teach Genie a repeatable procedure, such as your team's steps for a split-purchase test. It's in Preview, so it may not be turned on in your workspace yet.

Pin and organize

Pin the chats you return to, and give them clear names, such as FY26 DOT P-card testing, so you can find them again.

Send feedback

Mark a good answer Yes, or click Fix it when it's wrong. Request review flags an answer for the data team, who see your feedback and use it to improve the agent.

One long question with five conditions.Start simple, then add one condition per follow-up.
  • Name the measure, the slice and the time: spend by agency in FY2026.
  • Use the words in the data. If Genie doesn't know a term, define it in the chat or save it as a memory.

Cheat sheet

Asking well

  • Measure, slice and time: receipt rate by agency for Q1 FY2026.
  • Build up with follow-ups instead of one long question.
  • New topic, new chat.
  • Ask Genie to explain how you calculated this.
  • Agent mode for open questions; normal chat for quick facts.

Where things are

  • Genie One: app switcher, upper right.
  • Show code: under each answer.
  • Download and charts: on the result and in the side panel.
  • Scheduled tasks: Genie One sidebar.
  • Share: top of the chat.
  • Feedback: Yes, Fix it, or Request review under each answer.

Troubleshooting & FAQ

Genie gave me an empty answer or said it can't find the data

Genie only uses data you have permission to see. An empty answer often means your account doesn't have access to that table yet. Ask the data team.

My colleague asked the same question and got a different number

Check two things. First, open Show code on both answers, because a small wording difference can change a filter or a date range. Second, you may have different access: row filters can show each person only the rows they're allowed to see.

Can Genie change or delete data?

No. Genie answers questions by reading data. Nothing you ask in a chat changes the underlying tables.

Does Genie send our data to an outside model?

To write a query, Genie sends your question and the table and column descriptions to the model. The query itself runs inside OSA's Databricks workspace, under your permissions.

The answer looks wrong

Read Show code, rephrase with the exact measure, slice and time period, or start a new chat. If it's still wrong, click Fix it or Request review so the data team can correct the agent.

My old results are gone

Query results are kept for 7 days. The chat stays in your history, so open it and run the question again.

Who sees a chat I share?

Only the people allowed by the sharing level you pick. By default, the agent's managers can review it. Recipients see it read-only, and they still need access to the data.
