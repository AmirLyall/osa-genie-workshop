Meet the data

The workshop uses one schema of synthetic P-card data covering FY2025 and FY2026 (July 2024 through June 2026), with about 1,800 cards and 180,000 purchases. Every table and column has a plain-English description in Unity Catalog. Genie reads those descriptions, which is a big part of why it can turn your words into the right query.

Schema osa_pcard_review, in the catalog the data team chose: a statewide view of purchasing card activity across 12 fictional agencies.

TableGrainWhat's in it
agencies1 row / agencyAgency code and name.
agency_budgets1 row / agency / fiscal yearEach agency's P-card budget for FY2025 and FY2026.
cardholders1 row / cardAgency, card status, single-purchase and monthly limits, employee status, and a termination date if the employee has left.
transactions1 row / purchaseDate and time, amount, merchant, merchant category code (MCC), and whether a receipt is attached.
merchant_categories1 row / MCCCategory description and whether the category is blocked under card policy.
monthly_statements1 row / card / monthStatement total, whether it was reconciled, the reconciliation date, and the approver.
The data stops on June 30, 2026. Genie doesn't know that, so "last 90 days" or "yesterday" would count back from today and find nothing. Use real dates instead, as today's questions do.
Things planted in the data for you to find: split purchases kept just under a card's limit, purchases on cards after the employee left, blocked merchant categories, weekend and late-night activity, missing receipts, and statements reconciled late or not at all.

1 Genie One, Genie Agents, and trust

Goal: know where Genie lives, what each part is for, and why its answers are safe to work with. 12:00 · 10 min

Genie One

Your home page for data at OSA (it used to be called Databricks One). The sidebar has New chat, Agents, Discover, My stuff, Schedules, Customizations and Search chats.

Genie Agents

A chat focused on one subject, such as P-card activity, that answers questions from a set of tables you choose. Genie Agents used to be called Genie spaces. Data teams usually add definitions and examples so the agent speaks your language. Today you'll start from just the tables.

Why you can trust what it shows you

  • It only sees what you can see. Every answer runs with your own Unity Catalog permissions. Row filters and column masks apply automatically, so two people can ask the same question and see different results.
  • It shows its work. Every answer comes with the query Genie ran, so you can check it the same way you'd check a colleague's spreadsheet.
  • It can still be wrong. Genie is a fast first draft, not a second reviewer. Verify before a number goes into a workpaper or a report.
Names change between releases. If a button isn't exactly where this guide says, look for the same word nearby.

How the data team makes an agent smarter, and how you can help

A new agent only knows what's in the tables. The data team has several ways to teach it more. They don't know your work the way you do, so the most useful thing you can bring them is the knowledge behind each one.

Lower layers are more deterministic. Every piece of business logic should live as far down as possible.

Last option, least reliable

Text instructionsFast but optimistic

Text instructions: formatting, scope and clarification prompts. Great for fast iteration and subjective changes, but open to interpretation, and they can be ignored if the context gets overloaded.

SQL expressionsExample-based pattern matching for reliable outcomes

SQL expressions: Genie's strongest signal for writing queries. It learns from examples, which captures your team's expertise.

Unity Catalog metadataTable and column descriptions, synonyms, table context

Unity Catalog metadata: passive but important. It helps Genie pick the right tables and columns, and it helps everyone else who builds on Unity Catalog too.

Metric viewsEnforced semantic layer: calculations, joins, governed metrics

Metric views: enforced and deterministic. Calculations always run exactly as defined. You can add synonyms for KPIs, so Genie learns your business terms.

Preferred, most reliable

Your feedback is the starting point. When Genie misreads a term or joins the wrong tables, note it in the question template and share it with the data team. That's exactly what they use to tune the agent.

3 Navigate and ask

Goal: have a real conversation with your agent, and learn to check the work, not just read the answer. 12:20 · 15 min

Two ways to ask: Agent mode and Chat mode

Agent mode Default

Genie plans its approach, runs several queries, and writes up what it found with tables and charts. Best for open questions like "what should I test first?" It takes longer. Click Answer now to stop early, or Download PDF to keep the write-up.

Chat mode

Genie answers one question with one query, quickly. Best for quick facts, follow-ups and checking a single number. You can switch modes from the message box at any time.

As you work through the steps below, try the same question in both modes and compare: how long it takes, how many queries Genie runs in Show code, and how much it explains. Here's an open question to try in Agent mode:

Review fiscal year 2026 P-card activity for agency DCH and summarize the top risks an auditor should test first, with a supporting table for each.

  2. Only for agency DCH

    Now split that by quarter

  5. Show that as a bar chart

Habit to build: before you rely on an answer, ask yourself, "would I sign off on this query?" Reading Show code is how you test Genie's work, the same way you'd test any other evidence.
Results are kept for 7 days. Your chats stay in history, but query results expire after a week. Rerun the question or download what you need for the file.

You can add a CSV or Excel file to a chat and ask questions about it. Try it with our sample test workpaper.

No + button? File upload isn't available to every account type, or in the mobile app. Watch the demo and ask the data team about access.

Schedules

A scheduled task asks a question for you on a set schedule, posts the answer to a chat thread, and can email you the results with a PDF attached.

Using my P-card agent, list transactions from the most recent 7 days in the data that were at blocked merchant categories or made after the cardholder's termination date. Include agency, cardholder, merchant and amount.

The workshop data stops on June 30, 2026, so this task returns the same rows each time. On live data, each run picks up new activity.

Financial Audit idea

Weekly: statements still unreconciled after 30 days, by agency, with the dollar total.

Performance Audit idea

Monthly: missing-receipt rate by agency compared with the month before.

Skills Preview

A skill is a short instruction file you upload to teach Genie a repeatable procedure, such as your team's steps for a split-purchase test. It's in Preview, so it may not be turned on in your workspace yet.

Pin and organize

Pin the chats you return to, and give them clear names so you can find them again, for example:

Send feedback

Mark a good answer Yes, or click Fix it when it's wrong. On an agent someone else manages, Request review flags the answer for them so they can see where it needs work.

Goal: leave with the habits that get you the right answer the first time. 12:50 · 10 min

Rewrite the question, get a better answer

Instead ofTry
Show me card spending.

Total P-card spend by agency for fiscal year 2026.

Any fraud?

Transactions on cards after the cardholder's termination date in fiscal year 2026.

Recent problems with receipts.

Missing-receipt rate by agency for April to June 2026, compared with April to June 2025.

Why is DRB spending so much?

DRB P-card spend by merchant category group, fiscal year 2025 compared with fiscal year 2026.

Then ask Agent mode for the "why".
One long question with five conditions.Start simple, then add one condition per follow-up.
  • Name the measure, the slice and the time: spend by agency in FY2026.
  • Use the words in the data. If Genie doesn't know a term, define it in the chat or save it as a memory.
  • One topic per chat. Start a new chat when you change subjects so old context doesn't leak in.
  • Check Show code before a number goes into a workpaper.
  • Pick the right mode. Chat mode for what, which and how much. Agent mode for open questions that need several steps.

Capture your own questions

Think of the questions your team gets asked. For each one, try it in Genie and jot down what happened using the template below. Copy it into an email, a document or Teams, and share it with the OSA Data Analytics team. It tells them what the next Genie Agent should be able to answer.

Question:
Team (Financial Audit, Performance Audit, Rapid Response, other):
Who asks it:
What Genie did (right answer / close, needed rewording / wrong answer / data not available):
Notes (terms Genie needs defined, data it would need):

Questions Genie couldn't answer are just as useful as the ones it could. Write them in general terms, without case details, names or cardholder information.

Cheat sheet

Asking well

  • Measure, slice and time: receipt rate by agency for Q1 FY2026.
  • Build up with follow-ups instead of one long question.
  • New topic, new chat.
  • Ask Genie to explain itself:

    Explain how you calculated this.

  • Agent mode (the default) for open questions; Chat mode for quick facts.

Where things are

  • Show code: under each answer.
  • Download and charts: on the result and in the side panel.
  • New agent: workspace sidebar, Genie Agents, New.

  • Upload a file: the + in the message box.
  • Share: top of the chat.
  • Feedback: Yes, Fix it, or Request review under each answer.

Troubleshooting & FAQ

Genie gave me an empty answer or said it can't find the data

Genie only uses data you have permission to see. An empty answer often means your account doesn't have access to that table yet. Ask the data team.

I can't create an agent, or there's no Genie Agents item in my sidebar

Creating an agent needs the Databricks SQL entitlement, access to a SQL warehouse, and read access to the tables. Accounts that only use Genie One can't create agents. Ask the data team, and watch the shared screen in the meantime.

My colleague asked the same question and got a different number

Check two things. First, open Show code on both answers, because a small wording difference can change a filter or a date range. Second, you may have different access: row filters can show each person only the rows they're allowed to see.

Can Genie change or delete data?

No. Genie answers questions by reading data. Nothing you ask in a chat changes the underlying tables.

Does Genie send our data to an outside model?

To write a query, Genie uses your question and the table and column descriptions. The query itself runs inside OSA's Databricks workspace, under your permissions. Which AI models Genie may use is controlled by your workspace administrators, so ask the OSA data team about OSA's settings.

The answer looks wrong

Read Show code, rephrase with the exact measure, slice and time period, or start a new chat. If the agent keeps misreading a term, define it in your question or save it as a memory. On agents the data team manages, click Fix it or Request review so they can correct it.

My old results are gone

Query results are kept for 7 days. The chat stays in your history, so open it and run the question again.

Who sees a chat I share?

Only the people allowed by the sharing level you pick. Recipients see it read-only, and they still need access to the data.
