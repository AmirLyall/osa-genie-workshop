Facilitator guide

Before the session
  1. Make sure the agent exists in the workspace you'll present from. Run osa_genie_workshop_setup.py there (see Setup for the data team). For attendees to follow along, the data team runs it in their workspace and sets share_with_group to the business users' group.
  2. If the agent isn't set up where attendees can reach it, present from a demo workspace and have attendees watch. The guide still works as a take-home.
  3. Do a dry run as a business user, not as an admin: open Genie One, find the agent, ask a question, and upload osa_pcard_test_sample.csv. Accounts with only consumer access can't upload files.
  4. Confirm Agent mode is available, a scheduled task can send email, and whether Skills (Preview) is turned on. If it isn't, show Skills on a slide only.
  5. Pre-run the Agent mode prompt once so a finished result is ready if the live run is slow.
  6. Hybrid room: share one browser window at a large zoom, and have a second person watch the meeting chat.

Keep out of scope today

Building or curating agents (instructions, example SQL, trusted assets), benchmarks and Genie Workbench. Those are covered in a separate session for the data team. If someone asks how to fix a wrong answer, the business-user answer is Fix it or Request review.

If something breaks

If an answer is slow, move to the next block and come back to it. If upload or scheduling is blocked by an account setting, switch to the facilitator account and say so plainly. If the agent gives a wrong answer live, use it: open Show code, find the issue, and click Fix it. That's the lesson.
