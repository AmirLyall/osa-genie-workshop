Facilitator guide

Before the session
  1. Make sure the workshop tables are loaded in the workspace you'll present from. Run osa_genie_workshop_setup.py there (see Setup for the data team). For attendees to follow along, the data team runs it in their workspace and grants the attendees' group access.
  2. Do a dry run with an attendee-like account, not an admin: find the tables in Catalog, create an agent from Genie Agents, ask a question, and upload osa_pcard_test_sample.csv. Accounts without the Databricks SQL entitlement can't create agents, and consumer-only accounts can't upload files.
  3. Confirm Agent mode is available, a schedule can send email, and whether Skills (Preview) is turned on. If it isn't, show Skills on a slide only.
  4. If attendees can't create agents in their workspace, present from yours and have them watch. The guide still works as a take-home.
  5. Hybrid room: share one browser window at a large zoom, and have a second person watch the meeting chat.

Keep out of scope today

Hands-on tuning (writing instructions, example SQL, trusted assets, benchmarks) and Genie Workbench. Explain what each lever does and what business users can contribute, but leave the how-to for the data team's session. If someone asks how to fix a wrong answer, the business-user answer is to define the term in the question or save it as a memory.

If something breaks

If an answer is slow, move to the next block and come back to it. If creating, uploading or scheduling is blocked by an account setting, switch to your own screen and say so plainly. If the agent gives a wrong answer live, use it: open Show code, find the issue, and rephrase with a clearer definition. That's the lesson.
